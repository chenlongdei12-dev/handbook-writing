# examples/｜真实成品范例

两套**真实交付过**的课程手册（含讲师卡），全部按本 skill 的方法论产出。第一次使用本 skill 时，先扫一遍这两个范例，再看模板，体感会快很多。

## 看什么（对照 skill 要素）

| 看点 | 在哪 | 对应 skill 概念 |
|---|---|---|
| 开篇先亮成品（结果先行） | 两份手册的 00 章 | 结果先行 |
| 指令三段标签（读什么/做什么/规矩） | 手册正文代码块 + 附录A | 三段结构化标签 |
| 物料"开篇点名"清单表 | 手册 01 章 | 物料点名 |
| ⏳等待时间框（等待不干等） | 各实操章 | 等待时间利用 |
| 裸指令翻车 vs 规矩版对比 | 手册 06 章 | 认知冲突钩 |
| 选择题式暗号钩 | 手册 08 章末尾 | 行动钩 |
| 节奏表/保命提醒只出现在讲师卡 | 两份讲师批改卡 | 纯学员版 + 讲师卡分离 |
| 虚构场景"小满电商"与数据闭环 | 手册引用的物料数字 | 数据闭环 + 绝不编数 |

## 文件说明

- `第1节-Word课手册｜周五5点半，周报自己写好了.md` —— Word 场景：乱会议记录 → AI 周报
- `第1节-讲师批改卡.md` —— 内部资料范例（提交物核对/反馈三档/暗号 SOP）
- `第2节-Excel课手册｜一堆乱数据，自己长成一张会打分的表.md` —— Excel 场景：乱数据 → 自动打分表
- `第2节-讲师批改卡.md`

> 两份均为真实交付版式（仅做了公开适配），物料中的"小满电商"及全部人物、数据为**虚构演示数据**。
> 物料包（双 zip）体积原因未随仓库分发；需要完整跑一遍时，用 `scripts/pack_materials.py` 按手册中描述的物料清单自行生成即可。
