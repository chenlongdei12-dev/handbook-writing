# 主手册 13 章写作模板（生成新课程时对照填充）

> 本文件是 SKILL.md 的配套模板。生成新手册时逐章对照，替换 `<占位>` 内容。
> 完整成品范例见：真实成品范例见 `examples/` 目录（两节课完整手册）

## 顶部区（纯学员版，直接进正课）

```markdown
# 第N节课手册｜<钩子标题：结果句，如"一堆乱数据，自己长成一张会打分的表">

> **一句话说清这节课：** <谁+做什么+得到什么结果>

**你不需要懂任何技术。你只需要会：复制、粘贴、点按钮。**

自学全流程约 X 分钟。课堂版（讲 + 实操共 90 分钟）就六块：开头价值吸引，然后准备环境，接着连跑三个实操，后面钩子吸引，收尾布置作业。一天晚上，正好。

（❌ 不放：90分钟节奏表、给讲师的保命提醒、上节课回顾、"上节课的XX"式开头）
```

## 00 章｜先看结果，再说价值

1. **成品对比**：[📷 截图：乱材料 vs 成品] + "人做这套东西，4小时。AI做，几分钟。这节课结束，你的XX也这样。"
2. **真实玩家案例**（带出处的个人博主/实战玩家）：一句话场景 + 截图 + "你们每天做XX的，一模一样"
3. **四个"你将得到"**：✅流水线 / ✅规则方法 / ✅具体套路 / ✅等待时间玩法

## 01 章｜准备：搭环境

- 1.1 装软件（新任务→工作空间→打开本地文件夹；任务vs空间一句话："一次对话 vs 专用文件夹"）
- 1.2 认识四个抽屉（比喻表格：01原料堆/02车间/03展厅/04课后练习作业本）
- 1.3 解压物料包 + **物料开篇点名**（清单表格：文件/它是谁/干什么用 + 一句话联动"1是账2是人3是尺子"）+ ⚠️Win/Mac双包选择提示
- 1.4 找茬游戏：30秒眼扫乱数据找3处乱（把"乱"变成参与感）
- 1.5 安全底线（两层：本地受控=AI自动脱敏是技能 / 公网机密=手动先删铁律）

## 02-04 章｜实操一/二/三

每章固定节奏：

```markdown
## 0N｜实操X：<动作名>　`模块X`

做完这一步，<结果承诺>。

### N.1 先看清<要处理什么>（乱点清单表/规则白纸黑字）
### N.2 复制这条指令   ← "👆复制下面整段" + 三段标签代码块
### N.3 看它干活 + ⏳等待时间框（并行任务/小技巧/软广，同期不重复）
### N.4 验收（重点核对X处 + 💡小技巧如"右侧表格直接可编辑"）
### N.5 停60秒：指令解剖（给材料/给格式/给边界 ↔ 对应三段标签）
```

- 实操二（打分/规则类）：规则先看懂再发车；必配"规则一动表变脸"互动（改一个阈值重跑→"规则是你定的，AI看着办就是它编"）
- 实操三（报告类）：**HTML可视化主线**（双击浏览器打开/发群投屏）+ 分享两方式（发文件/在线链接+权限三档）+ "想要Word版？改一个词" + 云端展示页（只展示不教，如飞书AI字段捷径，⚠️官方警告原文）
- 对账压轴（如有）：算给学生看（"剔退款/补贴/重复后=XX"）→ 引爆跨课数据雷（"上节预估2.5万，实际1.56万——雷今天爆了，还是你亲手洗出来的"）

## 05 章｜你现在拥有了什么

- ✅成就清单（4项，含"等待时间的玩法"）
- 转折："但用两周你会发现——<手动环节还在>。要是它能<全自动>呢？——那是第N节的故事，也是有些人付费才能拿到的故事。"

（❌ 不放：99-指令库彩蛋——已删）

## 06 章｜同一份材料，两种命运（钩子核心）

结构（顺序勿变）：

1. **投屏处刑**（讲师投屏，学员围观）：新开对话窗口（⚠️加粗必须+原因）→ 发裸指令 → 四个检查点（编的统计量/口径偷换/真假混编）→ 与学员自己的规矩版产物并排——"差别不在AI，在你指令末尾那几行字"
2. **全员跟练 AI 自查指令**：逐个数字标"原数/算出（写算式）/材料中无出处"（"以后每份AI报告出炉都过一遍"）
3. 一句话衔接手册概念（大段复述只第一次讲，后续节一句话带过）

（❌ 学员不再自己发裸指令——避免文件搞混+省时间）

## 07 章｜企业案例

- 开头桥梁："工具会换，思路不变——乱数据进来，干净表出去，规则定好，人只看该看的那几行"
- 2-3个案例，数字全部带出处链接；主打案例放最后（细节展开+金句）
- 对照表："他们做的 / 你今晚做的"——"你亲手做过一遍缩小版"
- 点睛+"这话先放这，第08节末尾有入口"（给暗号钩铺垫）

## 08 章｜课后练习与阅读

- **课后练习**：物料包 `04-课后练习` 配好数据（同场景新数据集），三步=本节全流程重跑（清洗→自定规则打分→出报告）+ 自检清单3条
- **进阶题**（选做，深一层）：改权重解释业务含义 / 加一条行业规矩 / 换真实表（脱敏）跑
- **提交**：自愿但强建议（"交了有反馈，不交没人管你——但下节课你会发现练过的人上手快一倍"），姓名-第N节练习
- **课后阅读**3条（方法论延伸/案例原文/官方教程，附链接）
- 下节课预告（一句话回收本节伏笔，如"还记得那个卖点列吗"）
- 🎁**选择题式暗号钩**：对号入座 A销售客服/B运营门店/C财务行政 → "发这句暗号：【字母+表名+每天耗时】，限前15名"

## 附录A/B/C

- A：全部指令复贴（核心指令三段标签版 + AI自查 + 裸指令 + 等待时间并行小指令 + 日常微调话术表，微调表必含"换输出格式：Word/Excel/PPT"）
- B：常见问题6-8条（对照正文坑位；xlsx打不开/标红降级/AI删行/口径/并列/文件存哪了/积分不够）
- C：其他平台/备用工具（飞书/企微/钉钉入口+官方警告、豆包工作=对照组+"只能自家模型"、选型一句话"先看资料在哪"）

## 讲师练习卡模板（内部，不放学员手册）

```
# 讲师练习卡｜第N节练习
一、提交物核对（练习一条主线，2-3个检查点；没交的不追，群里一句"练过的上手快一倍"）
二、反馈话术三档（做得全/有瑕疵/只做了一段——不设星级退回，都给正向反馈）
三、顺手统计（好规则收集 / 产出完整学员标记=下节演示素材）
四、与下节课衔接点（伏笔回收提醒 / 等待素材下节避开）
五、私聊暗号承接SOP（当天必回 / ABC分层处理 / 算账共情→三步雏形→留钩 / 名额满话术）
（如需讲师专属内容：节奏表、保命提醒、开场话术填空、真实数字提醒——都放这里，不放学员手册）
```
