# 创作线：手册制作八步流程（含 30 条实战坑）

> 本文件是总路由的**创作线**子流程。生成手册/物料包/讲师卡时加载。适用于任何 Agent（Claude Code / WorkBuddy / Cursor / Codex CLI / OpenClaw 等）。
> 13 章逐章写作模板见 `references/handbook-template.md`（与本文件配套使用）。

## Overview

按"六模块课堂结构"生产一门 AI 办公实操课的全套交付物：主手册（学员用、纯学员视角）、物料包（双 zip）、讲师练习卡（内部用）。核心方法论：结果先行、指令内嵌（三段结构化标签）、等待时间利用、钩子分层、物料数据闭环。产出标准：初中文化能看懂、学员复制即用、每节课末尾留钩。

## 主手册 13 章固定结构（勿改序）

```
顶部：标题 + 一句话卖点（直接进正课，不设节奏表/保命提醒/上节课回顾）
00｜先看结果，再说价值 —— 成品对比 + 案例钩 + 四个"你将得到"
01｜准备：把环境搭好 —— 装软件 + 认抽屉 + 解压物料包（物料开篇点名）+ 安全底线
02｜实操一：<核心动作> —— 指令 + ⏳等待时间框 + 验收 + 指令解剖
03｜实操二：<打分/自动化> —— 规则白纸黑字 + 指令 + ⏳等待时间框 + 规则一动表变脸互动
04｜实操三：<可视化报告/分发> —— HTML主线（Word/Excel一词切换）+ ⏳等待时间框 + 云端展示页
05｜你现在拥有了什么（成就清单 + 转折）
06｜同一份材料，两种命运（讲师投屏处刑裸指令 + 学员只发AI自查指令）
07｜企业案例（带出处数字，个人→企业桥梁话术）
08｜课后练习与阅读（物料包内课后练习 + 进阶题 + 3条阅读 + 下节预告 + 暗号钩）
附录A｜指令速查表（全部指令+等待时间并行小指令+微调话术表）
附录B｜常见问题
附录C｜其他平台/备用工具路线
```

**硬规矩（三轮实战沉淀）：**

- 手册是**纯学员版**：不放课堂节奏表、保命提醒、"讲师话术"、"课上不解释"——这些归讲师练习卡
- 开头**不提上节课作业**、不写"上节课"式回顾——直接进本节内容（要回顾正文里自然带一句）
- 每条指令代码块内加**三段结构化标签**：`【1. 读哪些材料】`/`【2. 做什么&输出什么格式】`/`【3. 绝对不能破的规矩】`——与指令解剖的教学框架一一对应
- 报告类产出**HTML可视化为主线**（双击浏览器打开、发群投屏直观），Word/Excel/PPT 为"改一个词"的可选项——顺带教"输出格式是你说得算"
- **不用 99-指令库**（实测学员不用，已删）；不用"挑战作业+秒表计时"（学员没意识、徒增门槛）

## 六模块课堂结构（90分钟，一天晚上一节）

| 模块 | 时长 | 内容 |
|---|---|---|
| ①价值吸引 | 12min | 成品对比 → 真实玩家案例 → 四个"你将得到" |
| ②准备搭环境 | 10min | 装软件 + 解压物料包 + 找茬游戏（眼扫乱数据）+ 安全底线 |
| ③实操一 | 25min | 核心动作跑通 + ⏳等待时间框 + 验收对账 + 指令解剖 |
| ④实操二 | 15min | 规则先行 + 指令跑通 + ⏳等待时间框 + 规则一动表变脸 |
| ⑤实操三 | 12min | HTML报告主线 + ⏳等待时间框 + 分享/云端展示页 |
| ⑥钩子+练习 | 16min | 投屏处刑编数 + 企业案例 + 课后练习布置 + 暗号钩 |

## 制作流程（八步，按序执行）

### Step 1｜读取课程方案与定位

读用户提供的课程方案文档。提取每节课的：钩子标题、炫技开场、课上演示主线、"只教到"边界、"只展示不教"内容、企业案例（数字必须有出处）。若方案未给全，先向用户确认四个决策：发布平台、工具主线（主线+备选）、物料形式、使用场景。**系列课追加确认：是否同一批学员（决定等待素材是否可复用）。**

### Step 2｜设计虚构场景与数据闭环

**这是物料质量的核心。** 设计一个小团队场景（如"小满电商"运营组），人物 3-4 人有名有姓。物料间必须信息互相呼应：

- 周一会议提出的问题 → 周五复盘有跟进结果
- 数据文件里的数 → 与会议记录提到的数一致
- 留 1-2 处"材料里没有的数"（如环比、满意度、转化率）→ 供裸指令让 AI 编数翻车
- **跨课数据雷**：上一节的"预估数"在下一节用真实数据引爆（如第1节周报写"直播预估2.5万"→第2节洗出实收1.56万）——比任何说教都有说服力

数据要简单真实，并在数据物料标注"虚构演示数据"。**乱数据物料用 Python 生成并程序化校验合计自洽**（GMV=各行之和、退款/补贴/重复的勾稽关系要能算回来），不要手写。

### Step 3｜写核心指令（手册灵魂，精打细磨）

每节课的核心指令必须：嵌在正文代码块（"👆复制下面整段"）+ 附录A复贴一遍。指令用三段结构化标签：

```
【1. 读哪些材料】读哪个文件夹的哪些文件（含对照/字典文件）
【2. 做什么&输出什么格式】动作逐条 + 输出列/结构逐项列明（含存疑标记规则）
【3. 绝对不能破的规矩】"三条规矩"：不编不猜/动作留痕/口径交代——每节保持种子结构（付费伏笔：3条→30条手册）
```

另需配：一条"裸指令"（无规矩版，供投屏处刑翻车用）、一条"AI自查指令"（逐个数字标注"原数/算出（写算式）/材料中无出处"）、若干等待时间并行小指令。

### Step 4｜写物料包（双 zip 解压直出）

物料 = 课堂物料 3-4 份 + **课后练习物料 1 份**（放 `04-课后练习`）+ 使用说明。文件夹结构：

```
📁 我的AI<主题>
   📁 01-乱数据（或 01-材料）   ← 课堂物料
   📁 02-干净表格（或 02-成品） ← AI 产出落这里
   📁 03-分析报告（或 03-归档）
   📁 04-课后练习              ← 课后作业本，配练习数据
```

**物料格式铁律：Word/Excel 优先**——会议记录/需求单/说明书用 docx，数据表用 xlsx（openpyxl 生成，数值列设 number_format），聊天记录/使用说明用 txt。**绝不用 md 当学员物料**（学员打不开）。docx 用 python-docx 生成（微软雅黑中文字体，表格用 Table Grid 样式）。

**双 zip 打包（解决 Windows 解压中文乱码）：**

- **Win 版**：手工构造 zip 二进制——文件名 GBK 字节 + flag=0（Python zipfile 会强制置 UTF-8 flag 且 cp437 roundtrip 有损，**勿改回 zipfile 写 Win 版**）
- **Mac 版**：正常 UTF-8（zipfile 默认置 flag）
- 用 `scripts/pack_materials.py`（已内置双版本+验证），打包后必须验证：两版目录树正确、Win 版 GBK 还原名可读、`unzip -t` + `testzip()` 双验证
- 使用说明里写明"两个版本选对你的"

**课后练习物料设计**：换一个同场景新数据集（如课堂练直播订单→课后练门店退货），乱点类型与课堂一致但业务维度不同（练"口径统一/自定规则/出报告"），并**埋跨课伏笔呼应**（如退货原因"色差"呼应第1节的退货率数据）。难度=课堂的全流程重跑，另配 1-2 道进阶题加深一层（如"改打分权重看结果变化并解释业务含义"）。

### Step 5｜写主手册

按 13 章结构写（逐章模板见 `handbook-template.md`）。写作风格硬规矩：

- 一句一意，步骤动词开头（打开/点击/粘贴/拖进）
- 术语必配人话：文件夹＝抽屉柜；工作空间＝项目的专用柜；任务vs空间＝一次对话 vs 专用文件夹
- 每章开头写"做完这一步，你会得到……"
- 数字具体：不说"很快"，说"大约 2 分钟"
- 禁用词：赋能、抓手、闭环（讲解口径除外）、底层逻辑、颗粒度
- 引导语全文只在第 08 章末尾出现一次
- 截图位用 `[📷 截图：xxx]` 占位符，供课前补图
- 排版：锚点目录（`<a id="xx"></a>` + `[⬆ 返回目录]`）、指令块统一"👆复制下面整段"、⚠️坑位 blockquote、⏳等待时间框、✅成就清单
- 物料在 01 章开篇"点名亮相"：清单表格（文件/它是谁/干什么用）+ 一句话联动逻辑（"1是账，2是人，3是尺子"）
- 隐私话术两层闭环：本地受控环境可让 AI 清洗时自动脱敏（这本身是技能）；公网网页版 AI/核心机密=进对话框前手动删列，一步不省

### Step 6｜写钩子（三层，缺一不可）

1. **开场钩**（00章）：成品对比图 + 真实玩家案例（带出处的个人玩家，"他每天只做一件事：打开看板挑一条写"）+ "这节课结束，你的XX也这样"
2. **认知冲突钩**（06章）：**讲师投屏处刑**——新窗口发裸指令，大屏标出编的数（真假混编最毒）→ 与学员自己的规矩版产物并排对比 → "差别不在AI，在你指令末尾那几行字"。学员不动手（避免文件搞混+省时），只全员跟练 AI 自查指令
3. **行动钩**（08章末）：**选择题式暗号**——"发这句暗号：【字母 + 表名 + 每天耗时】"（A 销售/客服类、B 运营/门店类、C 财务/行政类），限前 15 名。选择题降低打字摩擦、字母自带客户分层（A 类离钱最近优先深聊）。企业案例（07章）开头必须有桥梁话术："工具会换，思路不变——乱数据进来，干净表出去，规则定好，人只看该看的那几行"

### Step 7｜设计课后练习（本节用精用透 + 进阶深一层）

- **原则**：作业的目的是把**本节内容**用精用透，不搞跨节串联、不搞手动对比实验（学员没有那个意识）
- **课后练习**（物料包 04 文件夹配好数据）：用新数据集重跑本节全流程（清洗→打分→报告），自检清单 3 条
- **进阶题**（选做，加深一层）：改打分权重并解释业务含义 / 往指令加一条自己行业的规矩 / 换自己真实工作表（脱敏）跑
- **课后阅读** 3 条：本节方法论延伸 + 企业案例原文 + 下一步工具官方教程（各附链接）
- **提交**：自愿但强建议（"交了有反馈，不交没人管你——但下节课你会发现练过的人上手快一倍"），命名 **姓名-第N节练习**

### Step 8｜写讲师练习卡 + 打包交付

练习卡（内部）：提交物核对表（练习只有一条主线，看 2-3 个点就够）、反馈话术三档（做得全/有瑕疵/只做了一段——**不设星级退回**，自愿提交都给正向反馈）、批改时顺手统计（好规则收集、产出表完整的学员标记=下节演示素材）、与下节课衔接点（伏笔回收提醒）、**私聊暗号承接SOP**（当天必回；按 ABC 字母分层处理；回复框架：算账共情→三步雏形→留钩；名额用完话术："排到下周统一回"）。

最后：通读校对（数据一致性 grep、旧引用遗留、指令块围栏成对、中文校验一律用 `grep -F` 固定串——BSD grep 多字节交替匹配会假阴性）、present_files 交付。

## ⏳ 等待时间设计（AI 生成有等待，等待不能干等）

**每条核心指令后配"⏳等待时间"框**，内容三类，混搭使用：

1. **并行任务**：开新窗口让 AI 干别的活（如"生成一份定制乱数据练习题"）——等待结束学员多拿一份副产品
2. **小技巧/软广**：装对照组 AI（豆包工作跑同指令=控制变量法）、语音输入、让 AI 反问你、先要计划再执行、模型选择（免费/快/强三档）、积分策略、右侧表格直接可编辑、分享权限三档
3. **案例软广**：让 AI 把大白话扩写成正式指令 → 与附录 A 对比 → "规矩它永远替你想不到"（付费价值的被动植入）

**同期不重复原则（重要）：**

- 同一期学员（如一期四场夜校）：四节课的等待时间内容**不得重复**——可以复习旧知识点（一句带过），但主体必须有新东西
- 跨期/新主题：可以复用过去准备好的素材库
- 生成系列课程时，先列一张**等待时间素材分配表**（每节分到哪些技巧/案例），再动笔，避免第三、四节课把第一、二节讲过的又讲一遍
- 讲师练习卡里注明本节等待框用了哪些素材、下节避开

## 写作风格总纲（判据：初中没毕业能看懂，高学历觉得通俗）

1. 结果先行：先看成品再讲怎么做；每步开头写得到什么
2. 淡化前提：准备工作≤1章讲完，全文不讲原理
3. 比喻兜底：每个新概念配一个生活比喻（抽屉/闹钟/账-人-尺子/教练场）
4. 真话垫底：凡有限制提前说破（电脑要开机/自查不能全信/豆包只能自家模型）——"实在"本身是信任钩
5. 荣誉感设计：✅成就感清单、"练过的人上手快一倍"式表述

## 与课程系列的衔接（生成后续课程时遵守）

- **跨课串联靠课堂产出，不靠课后作业**：本节课产出物（打分表含卖点列/客户名单）= 下节课的直接素材（表→PPT、卖点→海报），开场一句话回收伏笔（"还记得那个卖点列吗"）
- 企业案例按节分配不重复（1文档/2表格/3PPT/4办公系统）；**等待时间素材同样按节分配不重复**
- "手册"概念每节重复强化（3条→又3条→你的手册），但"看懂差距"式大段复述只讲一次，后续节一句话带过
- 练习卡"衔接点"必须写明：下节课怎么用本节产出、哪个伏笔开场回收、等待素材避开哪些

## 踩坑清单与解法（多轮真实课程迭代沉淀）

| # | 坑 | 解法（已固化到流程） |
|---|---|---|
| 1 | 学员手动建文件夹，15%会打错横线 | zip 直出完整文件夹结构，解压+拖桌面两步完事 |
| 2 | 对比实验在老窗口发裸指令，AI 记上下文不翻车 | 处刑必须新开对话窗口，加粗警示+讲清原因 |
| 3 | "到点自动跑"藏坑：本地 Agent 关机不执行 | 正文预期管理："电脑得开着"+预告云端方案 |
| 4 | 手册"有点浅"，学员只会抄 | ①指令解剖（三段标签）②投屏处刑抓错③AI自查指令，三件套补深度 |
| 5 | 个人小工具→企业大案例跳跃 | 案例前加桥梁："工具会换，思路不变" |
| 6 | 章节重排后旧交叉引用漏改 | 重排后 grep 全文旧编号逐一核对 |
| 7 | zip 中文文件名 Windows 自带解压乱码，讲师每次手动 Bandizip 重打包 | **双 zip**：Win 版 GBK 文件名（手工构造二进制）+ Mac 版 UTF-8，微信群直接发 Win 版 |
| 8 | 学员手册里裸露讲师视角内容（节奏表/保命提醒/"讲师话术"），神秘感破功 | 手册=纯学员版直接进正课；讲师内容全部归练习卡 |
| 9 | 开头"结算上节课作业"，没交的学员尴尬、讲的人尴尬 | 开头不提上节课，要回顾正文自然带一句 |
| 10 | "挑战作业+秒表计时+手动做下节的活"——学员没有跨节意识，完成率趋零 | 删挑战作业；课后练习=本节用精用透（物料包配好数据），进阶题加深一层 |
| 11 | 99-指令库彩蛋，学员根本不用 | 删掉，文件夹结构改四抽屉（01材料/02成品/03报告/04课后练习） |
| 12 | 等待时间全场干等 AI 生成，节奏塌掉 | 每条指令后配 ⏳等待时间框（并行任务/小技巧/软广），且同期四节不重复 |
| 13 | AI 生成报告只有 Word，发群/投屏不直观 | HTML 可视化看板为主线，输出格式一词切换（Word/Excel/PPT 均可选） |
| 14 | 打分公式"排名第1计1分"数学反面教材（第6名得分最高） | 用倒扣分制/高分靠前制，写完自己拿数据算一遍再入库 |
| 15 | 手册里写"最快的同学23分钟"等编造数字，学员手里有真数对不上 | 课堂引用数字一律讲师真实记录或填空式（____），绝不编数 |
| 16 | 隐私底线"先删再喂"与课堂"让 AI 洗时删隐私列"自相矛盾 | 两层闭环话术：本地受控=AI 批量脱敏是技能；公网/机密=手动先删的铁律 |
